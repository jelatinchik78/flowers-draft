# Flowers — черновик сайта

Черновик (первая половина работы) для цветочного магазина Flowers, Ревда.

Показать заказчику: дизайн, структура разделов, поведение каталога.

## Разделы

- `index.html` — главная: витрина, базовые букеты, как заказать
- `catalog.html` — букеты по ценовым сегментам + цветы поштучно
- `delivery.html` — доставка
- `payment.html` — оплата
- `care.html` — уход за букетом
- `contacts.html` — контакты

## Что в черновике условно

- Фотографий нет: вместо них рамки-заглушки, снимки магазин пришлёт позже
- Цены, тарифы доставки, часы работы — примерные
- Ссылка на MAX — заглушка, заказчик пришлёт позже
