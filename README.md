# Flowers — сайт цветочного магазина (Ревда)

Черновик первой половины работы: дизайн, структура разделов, каталог с ценовыми
сегментами и админ-панель для цен, наличия, ассортимента и фотографий.

## Страницы

- `index.html` — главная: первый экран, преимущества, базовые букеты, как заказать
- `catalog.html` — букеты по ценовым сегментам + цветы поштучно
- `delivery.html` — доставка
- `payment.html` — оплата
- `care.html` — уход за букетом
- `contacts.html` — контакты, адрес, часы работы

## Что в черновике условно

- Фотографий нет: вместо них рамки-заглушки — снимки магазин пришлёт позже
- Цены и состав букетов — примерные, до прайса от магазина
- Стоимость доставки до 3 000 ₽ и цена срочной доставки — «уточняйте при заказе»:
  точных цифр магазин пока не дал
- Ссылки на MAX и Instagram — заглушка / не добавлена (нужны адреса)
- Страницы закрыты от индексации (`noindex`)

Часы работы, зона доставки, бесплатная доставка от 3 000 ₽, фотоотчёт, скидка 10%
на предзаказ к праздникам — по тексту магазина от 25.11.2026.

## Админ-панель

Адрес: `/admin.php`
Стартовый пароль: `Flowers2026` — сразу смените его в разделе «Пароль».

Что можно делать:

- менять название, описание, цену и наличие;
- добавлять и удалять позиции, менять их порядок стрелками;
- загружать фотографию к позиции (JPEG, PNG, WebP до 15 МБ);
- указывать оптовую цену — она хранится отдельно и на сайт не выводится;
- менять пароль.

Фотография при загрузке поворачивается по EXIF (снимки с телефона не ложатся на
бок), уменьшается до 1600 px по длинной стороне и сохраняется в JPEG.

Изменения сразу видны на сайте: страницы статические, данные подтягиваются из
`data/catalog.json`.

## Файлы

```
admin.php            панель управления
admin/               шаблоны панели
admin.css            стили панели
config.php           настройки (пароль по умолчанию, размеры фото, таймзона)
lib/                 авторизация, хранилище, обработка фото
data/catalog.json    каталог для сайта (без оптовых цен)
data/wholesale.json  оптовые цены (закрыт от браузера)
data/backups/        10 последних копий каталога
img/catalog/         загруженные фотографии
```

`data/backups`, `data/wholesale.json`, `data/auth.json`, `lib/` и `config.php`
закрыты через `.htaccess` — на Apache они недоступны из браузера.

## Требования хостинга

- PHP 8.0+ с расширениями GD и EXIF (на Beget и Timeweb включены по умолчанию)
- Apache с поддержкой `.htaccess` (обычный виртуальный хостинг Beget/Timeweb)
- права на запись в `data/` и `img/catalog/` (обычно 755 для папок)

## Установка

1. Загрузить все файлы в корень сайта (`public_html` / `www`).
2. Открыть `https://домен/admin.php`, войти паролем `Flowers2026`.
3. Сменить пароль в разделе «Пароль».
4. Загрузить фотографии и выставить реальные цены.

Сборка не нужна, базы данных нет: это обычные файлы, которые работают как есть.
Ничего компилировать, устанавливать через терминал или импортировать в MySQL не надо.

Загружать можно целиком папку, вместе с подпапками `admin/`, `lib/`, `data/`,
`img/catalog/` и файлами `.htaccess`. Скрытые файлы FTP-клиент иногда не показывает —
включите показ скрытых, иначе `.htaccess` не скопируется и защита не заработает.

Полезно сразу удалить из загруженной копии лишнее: `README.md`, `.git/`, `.gitignore`.

### Права на папки

- `data/` — запись (обычно 755, файлы 644);
- `img/catalog/` — запись (755);
- остальное — только чтение.

Если на хостинге PHP работает от отдельного пользователя, папкам может понадобиться
775. Проверяется просто: зайти в админку и сохранить любую цену — если появилось
сообщение про права, выставить 775 на `data/` и `img/catalog/`.

### Если после загрузки «500» или пустая страница

- проверить версию PHP в панели хостинга (нужна 8.0+);
- включить `display_errors` на минуту или посмотреть лог ошибок сайта в панели;
- убедиться, что расширения GD и EXIF включены (на Beget и Timeweb — по умолчанию).

## Обновление сайта

Когда приходят новые файлы шаблонов, перезаписывать нужно только их: `*.html`,
`style.css`, `admin.css`, `js/`, `admin/`, `lib/`, `admin.php`, `config.php`.

**Не перезаписывать** `data/catalog.json` и папку `img/catalog/` — там живут
цены, наличие и загруженные фотографии. Иначе всё, что магазин менял через панель,
вернётся к исходному состоянию.

`config.php` перезаписывать можно, но только если пароль менялся через панель:
он хранится в `data/auth.json` и переживает замену `config.php`.

## Закрыть сайт от посторонних

Пока сайт не сдан, его можно закрыть паролем:

- в панели Beget: «Сайты» → нужный сайт → «Защита директории паролем» (Basic Auth);
- или загрузить `.htpasswd` рядом с `.htaccess` и добавить в `.htaccess`:

```
AuthType Basic
AuthName "Flowers"
AuthUserFile /home/логин/домен/.htpasswd
Require valid-user
```

Тогда сайт и админка спросят логин с паролем до показа содержимого. После сдачи
защиту снимают, а от индексации страницы уже закрыты `noindex` (его надо будет
убрать, когда сайт станет публичным).

## Публичная демо-версия

Демо на GitHub Pages: **https://jelatinchik78.github.io/flowers-draft/**

Обновляется автоматически после каждого пуша в `main` (сборка около минуты).
Публикуется только статическая часть: страницы, стили, скрипты и `data/catalog.json`.
PHP-файлы админки и конфиг из сборки исключены через `_config.yml` — на Pages они
отдают 404. Админка работает только на PHP-хостинге.

## Локальный просмотр

Сайт открывается и просто двойным щелчком по `index.html`: тогда каталог берётся
из резервного набора `js/catalog.js`. Чтобы проверить связку с админкой, нужен PHP:

```
php -S 127.0.0.1:8099 -t .
```

и адрес `http://127.0.0.1:8099/`.
